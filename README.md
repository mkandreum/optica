## ¿Qué es Óptica?

Óptica es una plataforma web de gestión para ópticas y centros visuales desarrollada por Xyon Platforms. Centraliza la gestión de clientes, órdenes de gafas, historial óptico y stock de productos en una sola herramienta.

## ✨ Funcionalidades

- **Gestión de clientes** e historial óptico
- **Órdenes de gafas** y lentes de contacto
- **Control de stock** de productos ópticos
- **Ficha óptica** digital por cliente
- **Panel de administración** del negocio
- **Despliegue self-hosted** vía Docker y Coolify

## 🛠️ Stack técnico

| Capa | Tecnología |
|------|----------|
| Frontend | React + TypeScript + Vite |
| Backend | Node.js + TypeScript |
| Despliegue | Docker + Coolify |

## 🚀 Instalación

```bash
git clone https://github.com/mkandreum/optica.git
cd optica
cp .env.example .env
docker-compose up -d
```

### Desarrollo local

```bash
npm install
npm run dev
```
